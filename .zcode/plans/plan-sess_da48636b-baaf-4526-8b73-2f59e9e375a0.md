# Rebuild Agentic Browser → BrowserOS-style AI browser

## Target
A Chromium-based (Electron) agentic browser in the BrowserOS visual language: near-black charcoal + orange accent + cream text, monospace "terminal" labels, a unified right-side AI Assistant panel (Chat/Agent modes), and a functional new-tab agent dashboard.

## Critical functional fixes (why it's broken now)
1. **React chrome is invisible.** `windowManager.ts` never calls `rendererView.setBounds(...)`, so the whole UI is 0×0. → Set renderer bounds to the full content area on init + resize (use `getContentBounds()`).
2. **New-tab page is dead static HTML.** `NEW_TAB_PAGE_HTML` is a `data:` URL with an unwired `<input>`. → Replace with a real React `NewTab` dashboard rendered in the content area; the tab's native view stays hidden while a tab is a "new tab".
3. **Native tab view would cover the side panel.** The tab `WebContentsView` is full-width and sits above the renderer, so it would overlap the Assistant panel. → Add a right-inset IPC so the tab view shrinks when the panel is open.
4. **Windows title bar.** Add `titleBarOverlay` (dark, 40px) so native min/max/close buttons blend into the tab strip; keep interactive buttons in the toolbar row below.

## Design system
- **Palette** (`tailwind.config.js`): `ink #0e0e10`, `panel #161619`, `panel2 #1d1d21`, `panel3 #26262b`, `line #2b2b31`, `cream #f2efe6`, `muted #9b9aa3`, `accent #f26522` (+ `accent-hover #ff7a3d`), agent status green/amber/red.
- **Type:** monospace stack for headings/terminal labels (`01 // AGENT`), refined system sans for body. No external font requests (privacy-first).
- **Motion/texture** (`index.css`): pulsing LIVE dot, fade-up cards, subtle grid + orange radial glow on the dashboard, thin dark scrollbars, orange selection.

## File changes

**Shared**
- `src/shared/types.ts`: add `isNewTab: boolean` to `TabInfo`; add `LAYOUT_INSETS` IPC channel.
- `src/shared/constants.ts`: add `CHROME_HEIGHT = 88`, `ASSISTANT_PANEL_WIDTH = 400`; remove `NEW_TAB_PAGE_HTML`.

**Main**
- `src/main/windowManager.ts`: keep `rendererView` ref; `layoutRendererView()` sets bounds to `getContentBounds()` (init + resize); add `titleBarOverlay`; use `CHROME_HEIGHT`; handle `LAYOUT_INSETS` (store right inset, re-layout tab).
- `src/main/tabManager.ts`: `createTab()` marks `isNewTab` when no URL and loads nothing visible (view hidden); `navigateTab()` clears `isNewTab` and shows the view; `switchToTab()`/`layoutActiveTab()` hide the view for new tabs and honor the right inset; use `getContentBounds()` + `CHROME_HEIGHT`.
- `src/main/ipcHandlers.ts`: register `LAYOUT_INSETS` handler.
- `src/main/preload/index.ts` + `src/preload/index.d.ts`: expose `layout.setInsets(right)`.

**Renderer**
- `src/renderer/App.tsx`: new layout — tab strip (40px) + toolbar (48px) + content; render `<NewTab/>` in the content area when the active tab `isNewTab`; single `assistantOpen` + `assistantMode` state; call `setInsets(400|0)` on toggle; shortcuts Ctrl+B (chat), Ctrl+Shift+A (agent).
- `src/renderer/components/NewTab/NewTab.tsx` (new): time-based greeting + big display headline; functional search/command bar (Enter → `navigateTab`; `>` prefix → `startAgent`); live running-agent card (from `agentStore`, Watch/Stop); shortcut tiles (letter tiles, no external favicons); ambient background.
- `src/renderer/components/Assistant/AssistantPanel.tsx` (new): right panel (400px) with Chat/Agent mode toggle + close; hosts the chat and agent bodies.
- `src/renderer/components/ChatPanel/ChatPanel.tsx` & `Supervisor/Supervisor.tsx`: restyle to the new theme; drop their own header/close (AssistantPanel owns the chrome).
- `src/renderer/components/TabBar/TabBar.tsx`: dark strip, orange active indicator, hover close, left-aligned tabs + "+".
- `src/renderer/components/AddressBar/AddressBar.tsx`: restyle into toolbar — nav buttons, mono address input, Assistant button, settings.
- `src/renderer/components/CommandPalette/CommandPalette.tsx` & `Settings/SettingsPanel.tsx`: restyle to theme (keep model lists as-is).
- `src/renderer/styles/index.css`: base theme, fonts, scrollbars, keyframes, ambient utilities.
- `tailwind.config.js`: palette + font stacks.

## Verification
- `tsc --noEmit` for both `tsconfig.node.json` and `tsconfig.web.json`.
- `electron-vite build` succeeds (main/preload/renderer).
- `electron-vite dev` launches and stays running; you eyeball the new UI, type in the new-tab search to confirm it navigates, and toggle the Assistant panel.
